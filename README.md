# TextMind

TextMind 是一个本地优先的个人知识管理与 AI 辅助学习系统，重点探索自然语言处理（NLP）技术在个人知识检索、知识加工和检索评估中的应用。

项目目前处于**需求探索与技术验证阶段**。本文档用于介绍项目方向和文档入口，不代表需求规格说明书（SRS）已经冻结。

## 项目方向

TextMind 以知识库为中心，围绕以下工作流组织功能：

1. 将 TXT、Markdown 等文本资料导入知识库。
2. 对知识库内容进行解析、分块和索引。
3. 使用关键词检索、语义检索及混合检索查找知识。
4. 基于检索结果进行问答、总结、知识点提取等 AI 加工。
5. 将 AI 加工成果保存为可移植的 Markdown 笔记。
6. 在检索实验室中比较检索算法与参数，并将合适的配置应用到知识管理工作台。

项目包含两个相互配合的主要模块：

- **知识管理工作台**：面向日常资料管理、检索和 AI 知识加工。
- **检索实验室**：面向数据集、算法配置、实验运行、指标评估和结果比较。
