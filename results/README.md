# 结果目录说明

`results/` 保存 TextMind 运行记录。记录的来源只由顶层目录决定，`run.json` 内不保存来源、导入时间或管理字段。

## 1. 三类目录

| 目录 | 来源 | 说明 |
| --- | --- | --- |
| `presets/` | 预置结果 | 随软件提供的只读参考结果 |
| `runs/` | 本机运行 | 在应用中运行实验生成 |
| `imports/` | 导入记录 | 通过历史页“导入单个 JSON”写入 |

每个记录位于 `results/<来源>/<run_id>/`：

```text
results/runs/<run_id>/
  run.json
  charts/
    metrics.png
    timing.png
```

- `run.json` 是运行记录的唯一事实源，字段遵循 `schemas/run_record.schema.json`。
- `charts` 字段中的路径是相对记录目录的 POSIX 路径。
- 应用读取图表时会校验路径仍在记录目录内且文件可读；越界、符号链接逃逸或不可读都会显示“图表不可用”。

## 2. 移动记录

- 移动整个记录目录（同时包含 `run.json` 和 `charts/`）可以保留图表。
- 只移动 `run.json` 会导致图表不可用；记录本身仍可查看，缺失图表逐项显示“图表不可用”。
- 目录名必须与 `run.json` 中的 `run_id` 一致，否则该记录会被标记为不可用记录。
- 同一 `run_id` 出现在多个来源时会被标记为冲突，应用不会任意选择其中一条。

## 3. 删除记录

- 只删除 `run.json`：该记录在历史中显示为不可用记录。
- 只删除图表文件：记录仍可查看，对应图表显示“图表不可用”。
- 删除整个记录目录：记录从历史中消失。
- 应用内不提供删除或恢复功能，请使用操作系统文件管理器操作。
- 预置结果（`presets/`）被删除后不会自动恢复；如需恢复，请重新获取软件包或重新构建预置结果。

## 4. 导入记录

通过历史页“导入单个 JSON”写入 `imports/<run_id>/run.json`：

- 上传内容按原始字节保存，应用不修改 JSON 字段、格式或缩进。
- 图表不会随 JSON 导入；导入成功后结果页会提示缺失图表。
- 可将图表文件手动复制到 `imports/<run_id>/charts/`，结果页每次读取时会重新检测。
- 三类来源中已存在的 Run ID 不允许导入覆盖；导入使用暂存目录与原子重命名。
