# 当前阶段待决定事项

> 本文件只记录当前课程项目范围内尚未确定的事项。未来知识管理产品方向的交互和工程问题暂不作为当前开发任务。

## 1. 数据集

- 正式实验优先采用哪个中文检索数据集。
- 是否额外采用一个规模较小的英文数据集作为流程验证 / 跨语言补充。
- 数据集具体版本、许可证和引用要求。
- 数据集原始格式到项目统一格式的转换规则。
- 是否需要对大型数据集制作固定、可复现的开发子集。

候选数据集与当前调研结果见 [datasets.md](../datasets.md)。

## 2. 检索方法与模型

- BM25 的实现库与中文分词方案。
- Dense Retrieval 的向量相似度计算与索引方式。
- 首轮比较哪些 Embedding 模型，以及是否全部能在 Apple Silicon MPS 上运行。
- 是否有时间实现 Hybrid Retrieval（BM25 + Dense + RRF）。

## 3. 评价方法

- Precision@K、Recall@K、MRR、NDCG@K 的具体计算和宏平均方式。
- 默认 K 值与是否同时报告多个 K。
- 无相关文档 Query 的处理规则。
- 检索耗时的重复次数、预热策略和统计口径。

## 4. 实验产物

- 实验配置和结果的 JSON / CSV 字段。
- 结果图表的具体形式。
- 课程展示需要保留哪些查询级案例和错误分析。

## 5. 当前明确后置

- GUI、桌面应用和产品化交互。
- 个人知识库管理、文件浏览、文件同步。
- AI 问答、摘要、笔记生成和聊天历史。
- Reranker、模型微调和自动网格搜索。
- 完整实验管理数据库和复杂历史记录界面。

这些事项不阻止当前最小实验程序开始实现。
