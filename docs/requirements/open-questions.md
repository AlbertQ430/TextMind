- 确认各预设实验对应的预置结果文件与图表文件。

## 2. 文件与数据规范

- 定义 JSON Schema 的必需字段、可选字段、格式版本和兼容策略。
- 定义实验方案 ID、运行 ID 的格式及唯一性保证。
- 定义预置结果、用户运行记录、导入记录的目录组织。
- 定义图表命名、相对路径解析基准、导入校验和缺失图表提示。
- 编写 results/README.md，说明记录目录结构、JSON 与图表关系，以及用户通过文件管理器删除记录的后果。

## 3. 资源与交付规范

- 确认 SciFact 随软件分发时的目录组织、来源 / 署名文件和许可证文本。
- 明确 DuRetrieval 的获取说明、目录约定和完整性检查规则。
- 明确统一模型根目录下各预设模型的子目录命名和必要文件检查规则。
- 根据现有实验环境核对支持的 Python 版本、依赖锁定文件和安装脚本行为。
- 确认 Windows 与 macOS 的安装、检查和启动脚本入口及 README 使用说明。

## 4. 技术设计阶段处理（不阻塞产品需求冻结）
