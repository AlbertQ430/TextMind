# TextMind 待讨论与待决定事项

> 本文记录尚未形成明确结论的事项。它们不应被误读为已经承诺实现的首版需求。随着讨论推进，应将已决定事项迁移到对应需求文档。

## 1. 产品与交互

- 知识库首页的具体布局和信息层级。
- 文件浏览、预览和原文定位的交互细节。
- AI 问答引用的具体展示方式，以及如何从引用跳转到原文。
- AI 成果的浏览、分类和管理方式。
- AI 成果是否默认参与检索，以及用户如何控制纳入范围。
- 首版内置 AI 任务的最终清单。

## 2. 检索技术

- 最终采用的 Embedding 模型。Qwen/Qwen3-Embedding-0.6B 已完成初步技术验证，但尚未正式选定为最终模型。
- BM25 的具体实现和中文分词方案。
- Dense Search 的向量索引实现。
- Hybrid Search 的 RRF 参数和融合细节。
- 默认 Chunk Size、Overlap 等分块参数。
- 是否在首版实现知识库级检索配置覆盖全局配置，还是先采用全局统一配置。

## 3. 检索实验室

- 最终采用哪些公开数据集，以及具体版本、许可证和下载方式。
- 自定义数据集的完整格式校验规则和错误提示。
- Precision@K、Recall@K、MRR、NDCG@K 的具体计算与聚合约定，包括无相关文档 Query 的处理方式。
- 默认 K 值和可选 K 值范围。
- 批量实验中预热、运行顺序和资源复用的具体规范。
- 实验取消、失败、部分完成和恢复机制。
- CSV / JSON 导出的具体字段和文件组织方式。
- 实验配置和实验结果的详细管理交互。
- 现有知识库实验的基本语料信息具体记录字段。

## 4. 工程实现

- GUI 框架和整体技术栈。
- SQLite 数据库结构与元数据设计。
- 知识库目录及 `.textmind/` 内部目录的最终结构。
- 文件变化检测与增量同步实现。
- 索引重建、损坏恢复和异常处理机制。
- 本地模型管理、模型缓存和首次下载流程。
- 云端 AI API 的接口抽象与配置方式。
- 软件打包、安装和运行环境要求。

## 5. 课程展示与实验计划

- 最终用于正式实验的数据集及规模。
- BM25、Dense Search、Hybrid Search 的对照实验设计。
- 分块参数对检索效果的影响实验。
- 检索配置的实验结果图表。
- 模型与系统流程图。
- 三分钟课堂讲演的内容组织。

## 6. 暂不纳入首版重点的内容

以下内容目前明确后置或不作为首版重点：
- Reranker。
- 自动网格搜索或自动参数搜索。
- 人工标注界面。
- 实时文件监听与实时同步。
- 复杂的 AI 任务模板编辑器。
- 多轮 AI 对话历史管理。
- 复杂的短 Chunk 合并策略。
- 为现有知识库实验建立完整语料快照。

“后置”不代表永远不做，只表示首版不应因此扩大实现范围。
