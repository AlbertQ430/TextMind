# TextMind SRS v0.2 至 SDS 需求追溯矩阵

> 检查日期：2026-11-21
>
> 需求基线：[SRS v0.2](../requirements/SRS.md)
>
> 设计基线：[SDS v0.1 评审通过版](SDS.md)
>
> 检查范围：SRS 第 7 节 AT-001 至 AT-036

## 1. 检查结论

SRS 的 36 条验收标准均已找到明确 SDS 设计落点：

| 统计项 | 数量 |
| --- | ---: |
| SRS 验收标准 | 36 |
| 已找到设计落点 | 36 |
| 设计缺口 | 0 |
| 尚未完成的实现验收 | 36 |

本矩阵证明设计覆盖完整，不代表软件已经实现或通过验收。实现阶段应按第 4 列建立自动化测试或人工验收记录。

检查中补齐的设计落点：

- 浏览器断连不取消任务的明确规则。
- 变体失败不自动重试、手动重跑生成新 Run ID。
- 结果页不展示 query 级检索结果。
- 应用不提供删除 API，删除后果由 `results/README.md` 说明。
- SciFact 来源、署名和许可证随包交付。
- 断开网络时禁止自动下载的验证设计。

## 3. 后续实现验收要求

- 实现阶段必须为每一条 AT 建立可追踪的测试用例编号或人工验收记录。
- 自动化测试优先覆盖配置校验、状态机、存储一致性、导入安全和计时口径。
- Windows、macOS 浏览器、局域网访问和许可证文件属于发布前人工验收项。
- SDS 发生设计变更时，应同步更新本矩阵及对应 SDS 章节。
