## 4. 结论

1. Dense 的 Top-1 命中率 82.6%，显著高于 BM25（66.1%）；Dense 的 Top-10 召回失败率仅 4.3%，说明中文语义模型已基本解决召回问题，剩余损失主要在排序。
2. `ranked_low` 案例（Dense 13.1%）多为语义近似但主题不同的同类文档（例如拆机类问题混淆不同型号），属于排序校准问题。
3. `miss_top_k` 案例（Dense 4.3%）集中在术语歧义、领域漂移（游戏术语、口语化短 query）以及短口语 query 与网页长文之间的语义鸿沟。
4. Hybrid 相对 Dense 的 Top-1 收益 79 条、损失 166 条（净变化 -87 条）；等权 RRF 在 BM25 明显弱于 Dense 时不占优，后续可尝试加权 RRF 或按数据集调低 BM25 权重。
