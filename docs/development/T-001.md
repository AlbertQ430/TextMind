## 1. 任务定义

### 1.1 目标

建立一个可由项目专用 Python 环境启动的最小 FastAPI 应用，并固定依赖安装、环境检查和启动入口，为后续任务提供稳定工程骨架。

### 1.2 范围

包含：

- Python 3.11 项目元数据和锁定依赖入口。
- FastAPI/Uvicorn/Jinja2/python-multipart/jsonschema/httpx 依赖声明。
- 项目专用虚拟环境安装脚本。
- 核心依赖和环境检查脚本。
- 仅监听 `127.0.0.1` 的启动脚本。
- `create_app()` 工厂和 `/api/v1/health`。
- 应用运行目录初始化。
- `.venv`、日志和本地应用数据忽略规则。

不包含：

- 方案配置和实验执行。
- 任务队列、SQLite 和结果记录。
- 完整 Web 页面。
- LAN 监听、访问码和会话系统。
- 自动下载模型或数据集。

### 1.3 允许修改

```text
.gitignore
README.md
pyproject.toml
requirements.lock
scripts/install.py
scripts/check_env.py
scripts/start.py
src/paths.py
src/web/__init__.py

test/test_scaffold.py
```

不得修改现有检索算法、数据文件、冻结 SRS 或通过版 SDS。确需增加文件时，在实现交接中说明用途。

### 1.4 依赖与前提

- Python 3.11.18 可用。
- 安装阶段可以访问依赖包源；运行阶段不得自动下载模型或数据集。
- 当前完整测试基线为 103 个单元测试通过。

## 2. 接口契约

### 2.1 应用工厂

```python
def create_app() -> FastAPI: ...
```

- 必须可由 `uvicorn web.app:create_app --factory --app-dir src` 启动。
- 测试通过 FastAPI TestClient 调用。
- 本任务不创建后台任务线程。

### 2.2 健康检查

```http
GET /api/v1/health
200 application/json
```

响应：

```json
{
  "status": "ok",
  "version": "0.1.0"
}
```

- 健康检查不读取模型或数据集。
- 不返回主机名、用户名、路径或环境变量。

### 2.3 路径接口

`src/paths.py` 至少提供：

- `PROJECT_ROOT`
- `DATA_DIR`
- `APP_DATA_DIR`
- `RESULTS_DIR`
- `PRESETS_DIR`
- `RUNS_DIR`
- `IMPORTS_DIR`
- `LOGS_DIR`

应用启动时幂等创建 `APP_DATA_DIR`、三类结果目录和 `LOGS_DIR`。不得清空已有目录。

### 2.4 安装脚本

`scripts/install.py`：

- 使用当前兼容 Python 创建项目根目录 `.venv`。
- 从 `requirements.lock` 安装锁定依赖。
- 不安装全局包。
- 不下载模型和数据集。
- 失败时输出可理解错误并返回非零退出码。

### 2.5 环境检查脚本

`scripts/check_env.py`：

- 检查 Python 3.11。
- 检查 FastAPI、Uvicorn、Jinja2、python-multipart、jsonschema、httpx、numpy、torch、transformers、sentence-transformers、jieba、matplotlib。
- 输出各项版本和通过 / 失败状态。
- 核心依赖缺失时返回非零退出码。
- 不初始化真实模型。

### 2.6 启动脚本

`scripts/start.py`：

- 默认监听 `127.0.0.1:8765`。
- 不监听 `0.0.0.0`。
- 启动前调用核心环境检查。
- 核心依赖失败时阻止启动并输出终端错误。
- 本任务不自动打开浏览器。

### 2.7 错误与边界

- 端口占用时输出明确错误并返回非零退出码。
- 目录创建失败时阻止启动。
- 不记录敏感环境变量。
- 不使用网络访问模型或数据资源。

### 2.8 兼容性

- 不改变现有数据格式、检索接口或 CLI 行为。
- 现有 103 个单元测试必须保持通过。

## 3. 实现约束

- 使用 FastAPI + Uvicorn，不引入 Node.js、数据库服务或容器。
- 依赖锁定必须可重现。
- 不复制现有检索算法。
- 不为后续 UI 提前添加空页面和假数据。

#### 接口实现

- `create_app() -> FastAPI`：注册 lifespan，启动时调用 `ensure_app_dirs()`；本任务不创建后台线程。可由 `uvicorn web.app:create_app --factory --app-dir src` 启动，也可由 TestClient 调用。
- `GET /api/v1/health`：返回 `200 application/json`，内容固定为 `{"status": "ok", "version": "0.1.0"}`；不读取模型、数据集或环境变量，不返回主机名、用户名、路径。
- `src/paths.py`：提供 `PROJECT_ROOT`、`DATA_DIR`、`APP_DATA_DIR`、`RESULTS_DIR`、`PRESETS_DIR`、`RUNS_DIR`、`IMPORTS_DIR`、`LOGS_DIR`；`ensure_app_dirs()` 仅 `mkdir(..., exist_ok=True)`，不清空、不删除已有目录或文件，创建失败抛出 `OSError` 由启动脚本阻止启动。
- `scripts/install.py`：解释器选择顺序为 `--python` → `TEXTMIND_PYTHON` → 当前解释器 → `PATH` 中的 `python3.11`，必须为 3.11；`.venv` 已存在但解释器不是 3.11 时报错并提示手动删除；依赖安装失败输出 pip 错误摘要并返回 1。
- `scripts/check_env.py`：检查 Python 3.11 与 12 项依赖（fastapi、uvicorn、jinja2、python-multipart、jsonschema、httpx、numpy、torch、transformers、sentence-transformers、jieba、matplotlib）；任一项缺失返回 1；不初始化模型、不访问网络。
- `scripts/start.py`：默认 `127.0.0.1:8765`，host 写死回环地址，不监听 `0.0.0.0`；启动前依次执行核心依赖检查、目录初始化、端口预检；依赖失败、目录创建失败或端口占用均输出明确错误并返回 1；不自动打开浏览器。
- 边界：环境检查把 transformers / sentence-transformers 也视为核心依赖（严格落实任务 §2.5），后续如需“无模型也可启动”的降级策略需在 T-009 调整。
