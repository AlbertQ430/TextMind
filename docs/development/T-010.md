## 1. 任务定义

### 1.1 目标

保持 Local App 始终监听回环地址，增加主机主动开启的第二个 LAN Uvicorn 监听器。两个 App 共享同一 AppContext、任务服务、历史记录和结果目录；LAN 客户端必须通过临时访问码登录并遵守受限权限。同时补齐队列取消提示的读取与确认。

### 1.2 范围

包含：

- Local/LAN 两种 App 权限模式和共享 AppContext。
- LAN Uvicorn 线程、端口、地址、启停和失败回滚。
- LAN 访问码生成、显示、常量时间比较和销毁。
- `local_authenticated`、`lan_preauth`、`lan_authenticated` 会话。
- 登录 CSRF、Origin/Referer、失败轮换和限流。
- 登录成功后 session ID/CSRF 轮换。
- LAN 会话过期、logout、关闭 LAN 和 SSE `session.expired`。
- LAN/Local 权限矩阵。
- Local-only 网络管理 API 和设置页控制。
- 队列取消 notices API、页面显示和确认。
- 启动脚本自动恢复 LAN 设置。

不包含：

- 公网访问、HTTPS、TLS、账号体系或多用户角色。
- LAN 修改设置、导入 JSON 或控制网络。
- 自动配置防火墙或路由器。
- T-011 的双平台真实双机网络验收。

## 2. App 模式

```python
AppMode = Literal["local", "lan"]
create_app(context=None, *, mode: AppMode = "local")
```

- 默认仍是 Local App。
- 两个 App 共享同一 SessionStore、TaskService、ResultCatalog 和 SettingsStore。
- LAN App 不创建第二任务服务、不复制结果、不管理共享 lifespan。
- 只有 Local App lifespan 启停共享 AppContext。

LAN App 不注册或不允许：

- JSON 导入。
- 设置页和设置修改。
- 资源路径/设备修改。
- LAN enable/disable。
- 任意主机文件路径接口。

直接访问也必须返回 403/404，不执行操作。

## 3. 网络生命周期

### 3.1 监听与地址

- Local：`127.0.0.1:<local_port>`。
- LAN：`0.0.0.0:<lan_port>`，仅开启后。
- 默认 LAN 端口 8766，且不得与本机端口相同。
- 同进程 Uvicorn Server 线程，不创建子进程。
- 客户端只显示非回环 IPv4 URL，如 `http://192.168.1.10:8766`，不显示 `0.0.0.0`。

### 3.2 开启

Local API 流程：

1. Local 会话、CSRF、端口校验。
2. 检查端口可用。
3. 生成高熵访问码。
4. 启动 LAN Server 线程并等待 ready。
5. ready 后原子保存 `lan_enabled=true` 和新端口。
6. 返回访问码、IPv4 地址和无 TLS 警告。

失败必须停止线程、清访问码/LAN 会话、保持设置为关闭并返回端口或防火墙建议。

### 3.3 启动恢复

- `scripts/start.py` 在 `lan_enabled=true` 时自动启动 LAN App。
- 每次进程启动生成新访问码，旧码不重用。
- 自动启动失败不阻止 Local App，Local 设置页显示原因并允许重试。
- 访问码只存内存，不进入设置、JSON、Cookie、URL 或日志。

### 3.4 关闭与进程退出

- Local 关闭 LAN API 立即停止接受新 LAN 请求、清访问码和全部 LAN 会话、发送 SSE 失效、保存 `lan_enabled=false`、停止并 join LAN 线程。
- Local 会话和任务不受影响。
- 正常进程退出关闭 listener/访问码/LAN 会话，但不强制持久化 `lan_enabled=false`；下次启动按设置恢复并生成新码。
- LAN 线程不得阻止进程退出。

## 4. 会话模型

Scope：

```text
local_authenticated
lan_preauth
lan_authenticated
```

有效期：

- Local：进程生命周期。
- `lan_preauth`：10 分钟。
- `lan_authenticated`：8 小时。

Session 至少包含 session ID、CSRF Token、scope、created_at、expires_at。SessionStore 必须线程安全，支持过期清理、创建指定 scope/TTL、轮换 CSRF、按 scope 批量删除。

Cookie：

- `textmind_session`
- Host-only，无 Domain
- `HttpOnly; SameSite=Strict; Path=/`
- HTTP 下无 Secure
- 只保存 session ID

## 5. LAN 登录

### 5.1 GET `/lan/login`

- 无会话时创建 `lan_preauth`、设置 Cookie、返回登录页。
- 已有 preauth 时复用并显示当前 CSRF。
- 已认证时重定向 `/plans`。
- `Cache-Control: no-store`。
- 页面包含 `_csrf`、访问码输入和 HTTP 风险提示。

### 5.2 POST `/lan/login`

字段：`_csrf`、`access_code`。

顺序：

1. 必须是 preauth 会话。
2. 校验显式 Origin。
3. Origin 缺失时校验 Referer。
4. 两者均缺失或不同源 → 拒绝。
5. 常量时间比较 CSRF。
6. 检查来源地址节流。
7. 常量时间比较访问码。

失败：

- 轮换当前 preauth CSRF。
- 增加会话与来源失败计数。
- 返回通用登录错误。
- 每会话最多 5 次，达到后 429、删除会话、清除 Cookie。
- 单来源 10 分钟最多 20 次失败，超过后 429。

成功：

1. 删除旧 preauth。
2. 创建新 `lan_authenticated` session ID 和 CSRF。
3. 设置新 Cookie。
4. 清除来源失败计数。
5. 重定向 `/plans`。

不得把 preauth 直接升级为 authenticated。

### 5.3 Logout

`POST /lan/logout` 仅对 LAN 认证会话开放，必须 CSRF + 同源，只删除当前会话并清 Cookie。

## 6. 权限矩阵

| 能力 | Local | LAN preauth | LAN authenticated |
| --- | --- | --- | --- |
| 登录页 | 不适用 | 是 | 重定向 |
| 方案、监控、结果、历史、比较 | 是 | 否 | 是 |
| 提交/取消任务、读取 SSE | 是 | 否 | 是 |
| 确认队列提示 | 是 | 否 | 是 |
| 设置、资源、设备 | 是 | 否 | 否 |
| JSON 导入 | 是 | 否 | 否 |
| LAN 开关 | 是 | 否 | 否 |
| `/lan/logout` | 不适用 | 否 | 是 |

- 未认证页面重定向登录；未认证 API 返回 401。
- 已认证无权限返回 403。
- LAN 页面隐藏设置和导入入口。
- 两个客户端共享同一任务、队列、历史，无客户端副本。

## 7. 网络 API

Local-only：

| 方法 | 路径 | 作用 |
| --- | --- | --- |
| `GET` | `/api/v1/network` | 监听、地址、访问码和 TLS 警告 |
| `POST` | `/api/v1/network/enable` | 开启监听 |
| `POST` | `/api/v1/network/disable` | 关闭监听并清 LAN 会话 |

Enable 请求：

```json
{"lan_port": 8766}
```

响应至少包含 `enabled`、`port`、`addresses`、`access_code`、`tls_warning`。

- 访问码只在 Local App 可见。
- 关闭后访问码为空。
- LAN App 无网络管理接口。
- 不把 `0.0.0.0` 返回为访问地址。

错误：

| HTTP | `code` | 场景 |
| --- | --- | --- |
| `422` | `NETWORK_PORT_INVALID` | 端口非法或与 Local 端口相同 |
| `409` | `NETWORK_PORT_IN_USE` | 端口占用 |
| `500` | `NETWORK_START_FAILED` | LAN Server 启动失败 |
| `500` | `NETWORK_WRITE_FAILED` | 设置持久化失败 |
| `503` | `NETWORK_UNAVAILABLE` | 网络控制器未装配 |

## 8. SSE

- Local SSE 继续使用 Local session。
- LAN SSE 只接受 authenticated LAN Cookie。
- LAN SSE 建立时要求显式同源 Origin。
- 每轮询/心跳重新检查 session、有效期和 LAN 开启状态。
- 失效时发送：

```text
event: session.expired
data: {"reason": "..."}
```

随后关闭，客户端停止自动重连。

- LAN SSE 不包含访问码、session ID、CSRF 或绝对路径。
- 关闭 LAN 后，即使任务继续运行，LAN 流也必须结束。

## 9. 队列取消提示

API：

| 方法 | 路径 | 作用 |
| --- | --- | --- |
| `GET` | `/api/v1/notices` | 未确认提示 |
| `POST` | `/api/v1/notices/{id}/ack` | 确认并删除 |

响应：

```json
{
  "notices": [
    {
      "id": 1,
      "kind": "queue_cancelled_on_restart",
      "count": 2,
      "message": "服务重启时取消了 2 个等待任务",
      "created_at": "..."
    }
  ]
}
```

- Local 和 LAN authenticated 均可读取/确认。
- ack 需要 CSRF。
- 无提示返回空数组。
- 内容不含任务配置或文件路径。
- 确认后跨刷新消失，未确认提示跨进程保留。

页面：

- Base 布局提供系统提示区域。
- 已认证页面加载后读取提示。
- 每条提示有“知道了”按钮。
- 确认成功后从 DOM 移除。
- 登录页不读取业务提示。

- `runtime.network.NetworkController` 负责端口校验、端口占用检测、生成访问码、启动/停止 Uvicorn 线程、失败回滚、地址过滤和登录失败限流。

- Local-only 网络 API 与设置页控制；LAN 不暴露网络管理。
- 队列提示 API 与 base 布局提示区域，支持读取、确认和跨进程保留。
- `scripts/start.py` 使用同一 context 创建 Local/LAN App，按设置恢复 LAN 并生成新码，退出时关闭监听和访问码。
