### 1.1 已确认的运行与结果规则

- 每次任务只执行一个实验变体，生成一份 JSON 和一个结果目录。
- 运行记录保存方案 ID、方案版本、变体 ID 和运行 ID。
- 同方案版本内可比较不同变体或同一变体的多次运行。
- DuRetrieval 等权 Hybrid 只归属方法对比方案，在 RRF 方案中作为只读参照。
- 单次运行图表只使用该变体自身数据；跨记录对比图由比较页面按需生成。
- 取消在主要阶段边界生效，不强制终止不可中断的模型加载和批量编码。
- 正常关闭和重启都会取消并清空等待队列；未完成运行标记为中断。
- 单变体失败只影响该记录，不设置方案级部分完成状态。
- 资源缺失只禁用受影响变体。
- 未知方案或变体允许只读导入但不能比较；重复运行 ID 导入被拒绝。
- 数据集规模可在方案详情或结果页展示，不再禁止显示。
- JSON 不保存结果来源和导入时间；来源由 `presets`、`runs`、`imports` 顶层目录区分。
- 用户单独移动 JSON 后导致来源或依赖图表失效，由用户自行负责。
- 多客户端一致性、正常关闭、耗时口径、路径越界、禁止自动下载和许可证随包等场景已写入 SRS v0.2 验收标准。

## 5. 明确不纳入 MVP

- 查询级检索结果、query 级诊断分布和错误分析案例展示。
- 实时详细日志流、整体百分比进度、自动重试和断点续跑。
- 多任务并行、任务优先级调整。
- 批量导入 JSON、再次导出导入记录、应用内删除记录。
- 复杂筛选、自定义指标、自动生成实验分析报告。
- 通用插件系统、任意第三方检索器和模型路径、自动调参。
- 个人知识库管理、AI 问答与笔记加工。
- 单条 Query 即时检索作为 MVP 的主要工作流。
- 云端部署、公网访问和多用户账号系统。
