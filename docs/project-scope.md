# TextMind 当前产品范围与阶段目标

> 最后更新：2026-11-21  
> 当前阶段：软件产品需求探索  
> 本文件记录目前已确认的产品边界；尚未冻结完整 SRS。

## 1. 产品定位

TextMind 正从文本检索算法实验项目演进为**文本检索实验台**。

当前 MVP 的目标是将已有文本检索实验封装成图形化、可交互的演示软件，让用户通过预设实验方案观察不同检索算法与 Embedding 模型的效果和运行表现。

当前产品问题：

> 用户如何方便地运行一组有代表性的文本检索基准实验，并理解不同方法的效果、耗时与差异？

## 2. 产品路线

采用 A（实验演示型）逐步演进到 B（有限实验配置型），不建设 C（通用实验研究平台）。

### A. 实验演示型 MVP

1. 提供预设基准实验方案（具体清单尚未确定）。
2. 为实验提供可直接浏览的预置结果。
3. 支持用户重新运行预设实验。
4. 展示指标、耗时、必要的检索结果和可视化。
5. 明确区分预置结果与实际运行结果。
6. 运行时展示阶段状态，不要求量化整体进度；允许用户取消运行。
7. 每次运行保存独立 JSON 记录和对应图表文件；支持导入单份 JSON 查看结果。

MVP 以整套数据集上的基准实验为主体，不以单条 Query 即时检索作为主要工作流。

### B. 后续有限配置能力

在 MVP 稳定后逐步开放：
- 在已支持范围内选择检索算法与 Embedding 模型。
- 调整有限的算法参数，例如 BM25 k1 / b、RRF 权重。
- 保存多次实验运行记录，并查看、比较同一实验方案的历史结果。
- 未来可视需求增加可选数据集。

A 应是 B 的受限模式：底层尽量共用实验方案、执行和结果处理流程，不维护两套独立系统。

### C. 不在产品路线内

- 任意第三方检索器或模型路径。
- 用户自定义检索器、自由组合流水线或通用插件系统。
- 批量参数搜索、自动调参和复杂实验组。
- 用户自定义评价指标。
- 面向研究人员的通用检索研究平台。

## 3. 当前明确不纳入 MVP 的功能

- 个人知识库管理、文件导入和文件浏览。
- 文档编辑、文件同步与目录扫描。
- AI 问答、摘要、笔记生成和聊天历史。
- 用户账号、云端同步和在线协作。
- 自定义数据集导入与自由实验配置。
- 单条 Query 即时检索作为主要产品流程。
- 批量导入实验 JSON、再次导出已导入的记录。

这些方向不构成当前 MVP 的前置依赖。

## 4. 实验结果与运行方式

采用“预置结果 + 重新运行”的组合方式：

- **预置结果**：项目预先运行并保存的样例结果，供用户快速浏览。
- **重新运行**：用户主动触发真实实验执行，产生新的运行结果。
- 两种结果必须标明来源与运行信息，不可混淆。
- 每次运行形成独立 JSON，不覆盖预置结果。
- 运行失败或被用户取消时，也保留运行记录和相应错误 / 取消信息。
- JSON 保存结构化配置、指标、耗时、状态、运行时间和格式版本等信息。
- 每次运行的图表作为独立图片文件保存，JSON 使用相对路径引用。
- 导入单份 JSON 时按相对路径尝试加载图表；图片缺失不应阻止 JSON 记录本身导入和查看。
- JSON 本身就是历史记录；删除 JSON 即删除该条记录。导入记录可参与同一实验方案的比较。
- 时间戳用于区分每次运行；稳定的实验方案 ID 用于归组同一方案的多次运行。
- 比较指标沿用 P@K、R@K、MRR、NDCG@K 和耗时，具体 K 值遵循实验方案设置。
- 图表覆盖算法、Embedding 模型、参数变化（如 RRF 权重）和耗时对比。
- 不提供不同实验方案之间的自由比较。

## 5. 数据集与模型分发

- **SciFact 默认随软件提供**，作为小规模英文演示 / 流程验证数据集。分发时应附带来源、署名及 CC-BY-SA-4.0 许可证说明。
- **DuRetrieval 不随软件提供**。软件提供数据集来源与获取说明，由有需要的用户自行下载。
- 当前阶段不随软件提供 Embedding 模型文件。
- 软件需标注 Python 环境要求和运行所需依赖；具体版本及环境配置方式仍待确定。

## 6. 技术方向（待架构设计验证）

- 优先复用现有 Python 检索与评价核心，不因 GUI 重写算法。
- CLI 与 GUI 尽量共用实验执行逻辑。
- 将实验方案、实验执行、实验结果处理保持清晰边界。
- 复用现有 JSON 等结构化实验结果；若格式不足，再制定兼容的扩展方案。
- 不为当前 MVP 引入通用插件架构或过度抽象。
- 运行任务需要向 GUI 提供阶段状态，并支持安全取消；具体机制待架构设计确定。

以上为技术方向，不替代后续架构设计和 SRS。

## 7. 已有基础

- BM25、Dense Retrieval、Hybrid Retrieval（RRF）已实现。
- SciFact 与 DuRetrieval 已完成实验闭环。
- 已有 Embedding 模型对比、查询前缀实验和加权 RRF 参数探索。
- 已生成结构化实验结果、汇总表、图表和错误分析材料。
- Apple Silicon MPS 的模型加载与向量计算链路已验证。
