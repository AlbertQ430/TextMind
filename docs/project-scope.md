# TextMind 当前产品范围与阶段目标

> 最后更新：2026-11-21  
> 当前阶段：SRS v0.2 已冻结，SDS v0.1 已通过设计评审，进入开发计划
> 本文件记录冻结版 SRS v0.2 对应的产品边界。

## 1. 产品定位

TextMind 正从文本检索算法实验项目演进为**文本检索实验台**。

当前 MVP 的目标是将已有文本检索实验封装成图形化、可交互的本地 Web 演示软件，让用户通过预设实验方案观察不同检索算法与 Embedding 模型的效果和运行表现。

当前产品问题：

> 用户如何方便地运行一组有代表性的文本检索基准实验，并理解不同方法的效果、耗时与差异？

## 2. 产品路线

采用 A（实验演示型）逐步演进到 B（有限实验配置型），不建设 C（通用实验研究平台）。

### A. 实验演示型 MVP

1. 提供沿用课程实验成果的预设基准实验方案，覆盖 SciFact 英文检索实验、DuRetrieval 中文检索实验和 DuRetrieval 加权 RRF 参数探索。实验方案用于归组，每次任务只运行一个实验变体。
2. 为每个预设变体提供可直接浏览的预置结果。
3. 支持用户重新运行任一可运行的预设变体。
4. 展示指标数值、耗时、适用图表及实验配置 / 运行环境信息；MVP 不展示查询级检索结果和错误分析案例。
5. 明确区分预置结果与实际运行结果。
6. 运行时展示阶段状态，不要求量化整体进度；允许用户取消运行。
7. 每次运行保存独立 JSON 记录和对应图表文件；支持导入单份 JSON 查看结果。
8. 提供实验中心、运行监控、实验结果、历史记录四个主要页面；资源与环境配置放在次级设置入口。

MVP 以整套数据集上的基准实验为主体，不以单条 Query 即时检索作为主要工作流。

### B. 后续有限配置能力

在 MVP 稳定后逐步开放：
- 在已支持范围内选择检索算法与 Embedding 模型。
- 调整有限的算法参数，例如 BM25 k1 / b、RRF 权重。
- 保存多次实验运行记录，并查看、比较同一方案及版本的历史结果。
- 未来可视需求增加可选数据集。

A 应是 B 的受限模式：底层尽量共用实验方案、执行和结果处理流程，不维护两套独立系统。

### C. 不在产品路线内

- 任意第三方检索器或模型路径。
- 用户自定义检索器、自由组合流水线或通用插件系统。
- 批量参数搜索、自动调参和复杂实验组。
- 用户自定义评价指标。
- 面向研究人员的通用检索研究平台。

## 3. 当前明确不纳入 MVP 的功能

- 个人知识库管理、文件导入和文件浏览。
- 文档编辑、文件同步与目录扫描。
- AI 问答、摘要、笔记生成和聊天历史。
- 用户账号、云端同步和在线协作。
- 自定义数据集导入与自由实验配置。
- 单条 Query 即时检索作为主要产品流程。
- 批量导入实验 JSON、再次导出已导入的记录。
- 云端部署和公网访问。

这些方向不构成当前 MVP 的前置依赖。

## 4. 本地 Web 应用形态

- TextMind 作为本地 Web 应用运行，由用户自己的电脑启动服务。
- 用户在主机本地通过浏览器访问。
- 可选开启局域网访问，其他设备通过主机局域网地址访问同一实例。
- 不依赖云服务器，不做公网访问和多用户账号系统。
- 后端统一管理实验任务、资源路径和结果文件；浏览器客户端不直接访问主机文件系统。
- 局域网客户端可同时查看任务状态与历史结果，但不能任意修改主机资源路径。

## 5. 页面与导航结构

采用左侧固定导航栏 + 右侧独立工作区。

- **实验中心**：浏览预设实验方案，选择其中一个变体并启动实验。
- **运行监控**：查看当前任务、等待队列、运行阶段和取消任务。
- **实验结果**：查看单次运行的指标数值、图表、实验配置和运行环境；查询级检索结果及错误分析案例留作后续扩展。
- **历史记录**：浏览历史运行记录、导入 JSON、选择并比较同一方案及版本内的记录；列表同时呈现本机运行与导入记录。
- **设置**：资源路径、Python 环境、局域网访问等次级配置。

这是已确认的页面级结构，页面内部交互和视觉细节仍待讨论。

## 6. 实验任务调度

- MVP 同一时间只运行一个实验变体；其他任务进入等待队列。
- 任务由后端统一管理，不由浏览器页面各自维护。
- 多个客户端可同时查看同一实例的任务状态和历史结果。
- 支持取消运行中的任务；取消在阶段边界生效，失败和取消均保留记录。
- 队列优先级已确定为提交顺序，局域网客户端可取消任务。
- 服务正常关闭时清空等待队列；服务重启后不恢复旧等待任务，未完成运行标记为中断。

## 7. 实验结果与运行方式

采用“预置结果 + 重新运行”的组合方式：

- **预置结果**：项目预先运行并保存的样例结果，供用户快速浏览。
- **重新运行**：用户主动触发单个变体的真实实验执行，产生新的运行结果。
- 预置结果、本机运行和导入记录由 `results/presets`、`results/runs`、`results/imports` 顶层目录区分，不可混淆。
- 每次单变体运行形成独立 JSON，不覆盖预置结果。
- 运行失败或正在执行的任务被用户取消时，保留运行记录和相应错误 / 取消信息；等待中的任务被取消时不生成记录。
- JSON 保存方案 ID 与版本、变体 ID、运行 ID、结构化配置、指标、耗时、状态、运行时间、格式版本和实验环境等信息。
- 实验环境信息用于描述运行条件，不记录不必要的个人或设备标识。
- 单次运行实际生成的图表作为独立图片文件保存，JSON 使用相对路径引用。
- 导入单份 JSON 时，将 JSON 和可用图表复制到 `results/imports/<run_id>/`，保持原 JSON 内容不变；图表缺失不应阻止 JSON 记录导入。
- 导入记录保留原始实验时间、配置和设备环境，并可参与同一方案及版本比较。
- 格式兼容但方案或变体未知的记录允许只读导入，但不能参与比较。
- 相同运行 ID 的导入被拒绝，不覆盖已有记录。
- JSON 格式版本不兼容时拒绝导入并说明原因。
- 不支持批量导入或再次导出导入记录。
- 应用内不提供删除记录功能；用户通过文件管理器删除整个运行目录。
- 历史记录列表展示方案名称、变体名称、方案版本、运行时间、状态、运行 ID 和代表性指标。
- JSON 不保存结果来源和导入时间；结果来源由 `presets`、`runs`、`imports` 顶层目录识别。
- results/README.md 说明 JSON 与图表的关系、目录组织方式，以及预置结果被删除后的影响。
- 时间戳用于区分每次运行；稳定的方案 ID、方案版本和变体 ID 用于归组与比较。
- 比较指标沿用 P@K、R@K、MRR、NDCG@K 和耗时，具体 K 值遵循实验变体设置。
- 比较页面可按所选记录生成算法、Embedding 模型、参数变化（如 RRF 权重）和耗时对比图。
- 单次运行页面不展示跨变体比较图。
- 不提供不同方案或不同方案版本之间的自由比较。

## 8. 数据集、模型与资源路径

- **SciFact 默认随软件提供**，作为小规模英文演示 / 流程验证数据集，并附带来源、署名及 CC-BY-SA-4.0 许可证说明。
- **DuRetrieval 不随软件提供**。软件提供数据集来源与获取说明，由用户自行下载并配置数据集目录。
- 当前阶段不随软件提供 Embedding 模型文件。
- 用户配置一个统一的模型根目录；TextMind 按预设模型名称在对应子目录中查找模型。
- 不提供单个模型独立路径配置。用户通过文件管理器整理模型目录，需要时修改统一根目录。
- TextMind 按变体检查数据集与模型路径、必要文件及可用性，并提示路径失效或资源不完整；资源缺失只禁用受影响变体。
- 不自动扫描磁盘、下载、复制、移动或整理数据集和模型文件。
- 资源路径由运行服务的主机配置；局域网客户端只查看资源状态，不任意修改主机路径。

## 9. Python 环境管理

- 复用现有 test 脚本的环境检查逻辑。
- 启动前 / 启动时检查 Python 版本、核心依赖、PyTorch 等必要条件，并提示缺失项。
- README 说明 Python、第三方库、推荐 Embedding 模型及使用步骤。
- 提供独立依赖安装脚本，由用户手动运行；脚本创建项目专用虚拟环境并安装锁定版本的依赖。
- 提供独立环境检查脚本，复用现有 test 检查逻辑，并在终端输出检查结果。
- 提供独立启动脚本启动本地 Web 服务；Windows 与 macOS 提供对应入口，底层逻辑尽量共用。
- 核心 Python 环境或依赖不满足时阻止启动；数据集或模型缺失时只将依赖该资源的实验标记为不可用。
- 不自动下载模型或数据集。

## 10. 技术方向（待架构设计验证）

- 优先复用现有 Python 检索与评价核心，不因 Web 界面重写算法。
- CLI 与 Web 尽量共用实验执行逻辑。
- 将实验方案、实验执行、实验结果处理保持清晰边界。
- 后端统一维护任务队列、运行状态、资源路径和结果文件。
- 不为当前 MVP 引入通用插件架构或过度抽象。
- 具体 Web 框架、API 设计、局域网访问控制和取消机制待架构设计确定。

## 11. 已有基础

- BM25、Dense Retrieval、Hybrid Retrieval（RRF）已实现。
- SciFact 与 DuRetrieval 已完成实验闭环。
- 已有 Embedding 模型对比、查询前缀实验和加权 RRF 参数探索。
- 已生成结构化实验结果、汇总表、图表和错误分析材料。
- Apple Silicon MPS 的模型加载与向量计算链路已验证。
